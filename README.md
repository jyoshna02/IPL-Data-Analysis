# IPL Data Analysis using Power BI

## 📌 Project Overview

The IPL Data Analysis project focuses on analyzing Indian Premier League (IPL) cricket data to uncover insights into team performance, player statistics, match results, and toss decisions.

Using Power BI, the project transforms cricket data into interactive dashboards that help users explore team and player performance across IPL seasons.

## 🎯 Project Objectives

- Analyze team performance and match outcomes.
- Identify top-performing batsmen and bowlers.
- Explore the impact of toss decisions on match results.
- Analyze winning trends across IPL seasons.
- Create interactive dashboards for cricket data visualization.

## 📂 Dataset

- **Dataset:** Indian Premier League (IPL) Match and Ball-by-Ball Data
- **Source:** [Kaggle – IPL Dataset](https://www.kaggle.com/datasets)
- **Data Includes:** Match details, teams, venues, toss decisions, winners, player performances, runs, wickets, and deliveries.

## 🛠️ Tools and Technologies

- **Power BI Desktop** – Interactive dashboard development
- **Power Query** – Data cleaning and transformation
- **DAX** – Calculated measures and KPIs
- **Data Visualization** – Charts, tables, cards, and slicers

## ⚙️ Project Workflow

1. **Data Collection:** Collected IPL match and player performance data.
2. **Data Cleaning:** Checked for missing values, duplicates, and inconsistent entries.
3. **Data Transformation:** Prepared the data for analysis using Power Query.
4. **Data Modeling:** Connected relevant tables for match and player analysis.
5. **DAX Calculations:** Created measures for matches played, wins, runs, and other performance indicators.
6. **Dashboard Development:** Built interactive Power BI reports.
7. **Insight Generation:** Identified trends in team performance, player statistics, and match outcomes.

## 📊 Dashboard Features

- Total matches played
- Total teams and seasons analyzed
- Most successful IPL teams
- Top run scorers
- Leading wicket-takers
- Toss decision and match outcome analysis
- Venue-wise match analysis
- Season-wise winning trends
- Interactive slicers for teams, seasons, and venues
